# Global Guidelines Template

Establish and document HTML coding standards, conventions, and best practices for a project.

## Overview

Consistent HTML standards improve accessibility, maintainability, and SEO across a project.
This template guides you through defining code style, semantic structure, progressive enhancement,
testing, performance, security, and documentation standards.

## Project Configuration

### Placeholders

| Placeholder | Description | Example |
|-------------|-------------|---------|
| `{{PROJECT_NAME}}` | Project name | `my-site` |
| `{{SITE_NAME}}` | Site display name | `My Website` |
| `{{BASE_URL}}` | Base URL | `https://example.com` |
| `{{SRC_DIR}}` | Source directory | `src/` |
| `{{DEFAULT_LANG}}` | Default language | `en` |

## When to Use

- Establishing HTML standards for a new project
- Documenting markup conventions for a team
- Creating an accessibility compliance guide
- Defining performance and security standards for markup
